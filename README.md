# 月墨幸存者

一个浏览器端类幸存者肉鸽游戏原型，主题是简约月墨美术、角色差异、自带武器、武器分支、能力、遗物、超武合成、宝箱奖励和构筑联动。

## 本地运行

这个项目是静态网页，可以直接用任意本地静态服务器打开：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 回归验证

项目包含 Playwright 回归脚本，用于检查页面加载、角色选择、移动、升级、分支、超武、宝箱、死亡结算和移动端布局等核心流程。

```bash
node regression-check.js
```

## 主要文件

- `index.html`：页面结构
- `styles.css`：界面、动效和响应式样式
- `game.js`：游戏逻辑、武器、能力、遗物、超武和特效
- `regression-check.js`：自动化回归验证
